# Demo script (75 to 90 seconds, screen recording, your voice)

Use a small real project of yours, not Spokeslad itself, so viewers see it on
something that isn't a demo.

1. **0:00 to 0:08.** Terminal with Claude Code open in the project. Voice: "I shipped
   something and need to tell people about it without sounding like an ad."
2. **0:08 to 0:20.** Run `/spokeslad:brief`. Fast-forward through repo reading. Show
   the positioning line and the approved-claims table it produced.
3. **0:20 to 0:32.** Run `/spokeslad:listen`. Show the digest: one competitor release,
   one HN mention, the "what to do" list.
4. **0:32 to 0:47.** Run `/spokeslad:plan "v1.2 adds offline mode"`. Show the tier
   score: tier 3, "this is a changelog post, not a launch". Voice: "It told me not to
   launch this. Good."
5. **0:47 to 1:05.** Run `/spokeslad:launch` on a bigger feature. Show the folder of
   drafts, then the linter failing one line ("3x faster" with no source). Fix it.
6. **1:05 to 1:18.** Open `redteam.md`. Show one blocking finding and the
   "first critical reply" for the Show HN draft.
7. **1:18 to 1:28.** Voice: "It never posts. I do." Show the repo URL and install
   command.

Keep it uncut where possible; speed up waits rather than editing results.
